## About Me

I work at the intersection of AI product delivery and AI governance research — building the systems that actually ship AI features while researching a question that grew directly out of that work: how do organisations define, or fail to define, the point at which an AI-driven decision should hand back to human judgement?

I designed and drove adoption of a Human-in-the-Loop validation framework for GenAI-driven decision workflows, and directed compliance efforts translating statutory requirements into deterministic system logic. I'm now researching this as a PhD candidate at Cork University Business School (UCC), examining the conditions under which organisations fail to define reverse-delegation thresholds for generative AI systems.

📍 Based in Cork, Ireland

## Featured Projects

### 🤖 [Digital Capacity Optimizer — AI-Driven Analytics Engine](https://github.com/sandesh-s-hegde/digital_capacity_optimizer)
> *Python · PostgreSQL · Google Gemini AI · GitHub Actions · CI/CD*

Decision-support system with a mandatory reverse-delegation checkpoint — the AI agent pauses generation, verifies against an external source, and only resumes once that check completes.

- **Conversational AI agent** with multi-turn context management and intent-routing logic
- **Stochastic simulation engine** running 10,000+ iterations to stress-test decision logic against edge cases before go-live
- **Full CI/CD pipeline** via GitHub Actions for automated deployment and validation
- **SQL reporting layer** tracking platform KPIs and performance benchmarks

### 🚚 [B2B Fleet Aggregator API](https://github.com/sandesh-s-hegde/b2b-fleet-aggregator-api)
> *Python · FastAPI · PostgreSQL · Neon · Render*

High-performance middleware bridging macro-strategic forecasting with micro-tactical fleet execution.

- **Dynamic Surge Pricing:** Automatically adjusts supplier rates based on real-time fleet utilization and availability algorithms
- **Aggregation Engine:** Consolidates multi-supplier capacity and prioritizes low-emission vehicle routing
- **Enterprise Architecture:** Deployed across a multi-cloud environment (Render & Neon) with comprehensive CI/CD, global exception handling, and observability telemetry

### 🤖 [RPA Legacy Freight Bridge — Hyperautomation API](https://github.com/sandesh-s-hegde/rpa-freight-bridge)
> *Python · FastAPI · UiPath · PostgreSQL · Docker · Prometheus*

Enterprise-grade hyperautomation bridge resolving the "digital disconnect" between modern AI orchestration and legacy, non-API freight carrier portals.

- **Asynchronous Execution:** Non-blocking Background Task model with `202 Accepted` status patterns, decoupling high-latency RPA workflows from upstream demand signals
- **Idempotent Transaction Logic:** Repository layer preventing redundant carrier bookings, ensuring financial consistency across distributed system retries
- **Robotic Orchestration:** Directly integrates with UiPath Orchestrator Queues to trigger unattended robots, translating JSON payloads into simulated UI keystrokes
- **Distributed Observability:** Full-stack tracing via `X-Correlation-ID` and Prometheus metrics for real-time system health monitoring

### 🌍 [ESG Grid Oracle — Carbon-Aware Routing Node](https://github.com/sandesh-s-hegde/esg-grid-oracle)
> *Python · FastAPI · Docker · GitHub Actions*

Sustainability layer connecting live European energy-grid data to supply chain routing decisions, built as a production-grade microservice with zero-trust API security and deterministic Green/Amber/Red dispatch signals for autonomous AI agents to act on directly.
